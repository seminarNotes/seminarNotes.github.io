Abstract

We propose an error-dynamics based data-driven MPC approach for trajectory tracking on mobile robots using Neural ODE. Rather than learning full system dynamics, we learn local error dynamics from demonstration data, enabling effective control with limited training samples. We design a Neural ODE-based error dynamics model and integrate it with Model Predictive Control, incorporating terminal constraints via Riccati/LMI methods for robustness. On simulated mobile robots with model uncertainty, our method achieves 73% error reduction (RMSE) compared to the baseline demo controller. The approach successfully transfers to real robot hardware without retraining, demonstrating effective trajectory tracking despite model mismatch.

Motivation & Background

Problem Statement

Model Predictive Control (MPC) requires accurate system models. When models are unavailable or inaccurate, tracking performance degrades significantly. Recent works attempt to address this by learning system dynamics using neural networks. However, this approach faces critical challenges:

  • High data requirements: Full system identification demands large amounts of training data
  • Reference trajectory estimation: Most methods require separate estimation of unmeasured reference inputs (e.g., reference torque)
  • Data efficiency: Traditional dynamics learning is sample-inefficient for control applications

Our Solution

Instead of learning full system dynamics, we learn error dynamics in the reference frame. We define the error in polar coordinate system as:

$$\rho_k = \sqrt{(x_{d,k}-x_k)^2 + (y_{d,k}-y_k)^2}, \quad \alpha_k = \mathrm{wrap}\,\Bigl(\mathrm{atan2}(y_{d,k}-y_k,\, x_{d,k}-x_k) - \theta_k\Bigr)$$

The error dynamics are learned as:

$$\mathbf{e}_{k+1} = F_{\Phi, \Psi} \left(\mathbf{e}_{k}, \mathbf{u}_{k} \right)$$

This approach offers several advantages:

  • Significantly reduced data requirements (leveraging demonstration trajectories)
  • No need for reference trajectory estimation (error is directly observable)
  • Better generalization across different tracking tasks

Proposed Approach

The control pipeline consists of three stages:

  • Stage 1 - Data Collection: Run the demo controller on diverse reference trajectories to collect error trajectories $\{e_k, u_k\}$
  • Stage 2 - Error Dynamics Learning: Train a Neural ODE model $F_{\Phi, \Psi}$ that predicts how tracking errors evolve under control inputs
  • Stage 3 - MPC Design: Formulate and solve a model predictive control problem using the learned error dynamics, with robust terminal constraints designed via LMI

2.1 Error Dynamics Based MPC

The core idea is to formulate the trajectory tracking problem in the error space. Given a demonstration (or reference trajectory), we define:

$$e(t) = x_{\text{ref}}(t) - x(t)$$

where $x_{\text{ref}}$ is the reference state from demonstration data and $x$ is the current state.

2.2 Neural ODE for Error Dynamics

We use Neural ODE to learn a continuous-time error dynamics model:

$$\frac{de}{dt} = \mathbf{f}_{\theta}(e, u)$$

The neural network $\mathbf{f}_{\theta}$ captures the dynamics of tracking errors given control inputs, enabling accurate error prediction over a prediction horizon.

2.3 MPC Design: Simulation (Nonlinear Dynamics)

In simulation, the MPC optimization problem with nonlinear error dynamics is formulated as:

$$\begin{align}\min_{\{\mathbf{u}_{k}\}_{k=0}^{N-1}}\ &{\sum_{k=0}^{N-1}\bigl(\mathbf{e}_{k}^{\top}Q\mathbf{e}_{k} +\mathbf{u}_{k}^{\top}R\mathbf{u}_{k} +\Delta \mathbf{u}_{k}^{\top}S\Delta \mathbf{u}_{k}\bigr) + \mathbf{e}_{N}^{\top}P\mathbf{e}_{N}} \\ \text{subject to:}\ &\mathbf{e}_{k+1} = F_{\Phi, \Psi} \left(\mathbf{e}_{k}, \mathbf{u}_{k} \right), \\ &\mathbf{e}_{\text{min}} \leq \mathbf{e}_{k} \leq \mathbf{e}_{\text{max}}, \quad\text{for } k=0,\cdots,N-1 \\ & \mathbf{u}_{\text{min}} \leq \mathbf{u}_{k} \leq \mathbf{u}_{\text{max}}, \quad\text{for } k=0,\cdots,N-1 \\ & \Delta \mathbf{u}_{\min} \le \Delta \mathbf{u}_k \le \Delta \mathbf{u}_{\max}, \quad\text{for } k=0,\cdots,N-1 \\ & \Delta \mathbf{u}_{k} :=\mathbf{u}_{k} - \mathbf{u}_{k-1} \\ &\mathbf{e}_{N}^{\top} P \mathbf{e}_{N} \leq 1, \quad \mathbf{u}_{\text{min}} \leq K\mathbf{e}_{N} \leq \mathbf{u}_{\text{max}}\end{align}$$

2.4 MPC Design: Real Robot (Linear Dynamics via Linearization)

For real robot deployment, we linearize the learned error dynamics around the equilibrium point to obtain a linear model. The MPC formulation with linear error dynamics is:

$$\begin{align}\min_{\{\mathbf{u}_{k}\}_{k=0}^{N-1}}\ &{\sum_{k=0}^{N-1}\bigl(\mathbf{e}_{k}^{\top}Q\mathbf{e}_{k} +\mathbf{u}_{k}^{\top}R\mathbf{u}_{k} +\Delta \mathbf{u}_{k}^{\top}S\Delta \mathbf{u}_{k}\bigr) + \mathbf{e}_{N}^{\top}P\mathbf{e}_{N}} \\ \text{subject to:}\ &\mathbf{e}_{k+1} = A\, \mathbf{e}_{k} + B\, \mathbf{u}_{k}, \\ &\mathbf{e}_{\text{min}} \leq \mathbf{e}_{k} \leq \mathbf{e}_{\text{max}}, \quad\text{for } k=0,\cdots,N-1 \\ & \mathbf{u}_{\text{min}} \leq \mathbf{u}_{k} \leq \mathbf{u}_{\text{max}}, \quad\text{for } k=0,\cdots,N-1 \\ & \Delta \mathbf{u}_{\min} \le \Delta \mathbf{u}_k \le \Delta \mathbf{u}_{\max}, \quad\text{for } k=0,\cdots,N-1 \\ & \Delta \mathbf{u}_{k} :=\mathbf{u}_{k} - \mathbf{u}_{k-1} \\ &\mathbf{e}_{N}^{\top} P \mathbf{e}_{N} \leq 1, \quad \mathbf{u}_{\text{min}} \leq K\mathbf{e}_{N} \leq \mathbf{u}_{\text{max}}\end{align}$$

2.5 Terminal Ingredients Design via LMI

The terminal cost matrix $P$ and feedback gain $K$ are computed to ensure robust stability and constraint satisfaction. The terminal ingredients satisfy the Lyapunov decrease condition:

$$\Delta V_{k} \leq -\mathbf{e}^{\top}_{k}Q\mathbf{e}_{k} - (K\mathbf{e}_{k})^{\top}RK\mathbf{e}_{k}+c||\mathbf{w}_{k}||^{2}$$

where $\Delta V_{k}:= V(\mathbf{e}_{k+1})-V(\mathbf{e}_{k})$ and $c >0$ quantifies the contribution of the mismatch energy to the Lyapunov difference.

The terminal region is defined as a normalized ellipsoidal set:

$$\Omega := \left\{ \mathbf{e}\in\mathbb{R}^{n_{\mathbf{e}}} : \mathbf{e}^{\top} P \mathbf{e} \leq 1 \right\}$$

To maximize the terminal set size, we perform the variable substitution $X:=P^{-1}>0$, $Y:=KX$, which gives:

$$K=YX^{-1}, \quad P = X^{-1}$$

The terminal ingredients are computed by solving the following SDP problem:

$$\begin{align}\max_{X>0,\,Y,\,c>0} & \log \det (X) \\ \text{subject to:}\ &\textbf{(LMI-D)}: \text{ enforces dissipativity decrease} \\ &\textbf{(LMI-U)}: \text{ ensures input admissibility}\end{align}$$

LMI-D (Dissipativity Decrease Condition):

$$\begin{bmatrix}X & (A\, X + B\, Y)^\top & (Q^{1/2}X)^\top & (R^{1/2}Y)^\top & X\\A\, X + B\, Y & X & 0 & 0 & 0\\Q^{1/2}X & 0 & I & 0 & 0\\R^{1/2}Y & 0 & 0 & I & 0\\X & 0 & 0 & 0 & cI\end{bmatrix}\succeq 0$$

LMI-U (Input Admissibility with symmetric box constraints $\mathbf{u}_{\max} = -\mathbf{u}_{\min}$): For each component $j$ ($1\leq j \leq n_{\mathbf{u}}$), define $\bar{\mathbf{u}}_{j} := (\mathbf{u}_{\max})_{j}$:

$$\begin{bmatrix} \bar{\mathbf{u}}_{j}^{2} & (Y)_{j} \\ (Y)_{j}^{\top} & X\end{bmatrix} \succeq 0$$

From the SDP solution $(X, Y, c)$, the terminal ingredients are recovered as:

$$P = X^{-1}, \quad K = YX^{-1}$$

Real Robot Implementation

4.1 Sim-to-Real Transfer

The controller learned in simulation is directly deployed on a real mobile robot without any retraining or fine-tuning. The robust MPC formulation (via Riccati/LMI terminal constraints) ensures stability despite inevitable model mismatch.

4.2 Real Robot Performance

The system successfully tracks reference trajectories on real hardware, demonstrating:

  • Effective error convergence despite model uncertainty
  • Smooth control inputs without chattering
  • Generalization to new trajectory patterns
